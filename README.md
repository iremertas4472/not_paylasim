# Öğrenci Not Paylaşım Uygulaması

Öğrencilerin ders notlarını (PDF) yükleyip paylaşabildiği, üniversite/program/sınıf/ders bazında arayabildiği bir mobil uygulama.

## Kullanılan Teknolojiler

- **Mobil:** Flutter (Dart)
- **Backend:** Node.js + Express
- **Veritabanı:** PostgreSQL
- **Dosya Yükleme:** Multer (backend), file_picker (mobil)
- **PDF Açma:** url_launcher (mobil, harici uygulamada açar)
